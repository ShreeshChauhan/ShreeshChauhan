# 🔎 Fraud Investigation Copilot

### `Python` · `PyTorch Geometric` · `GraphSAGE` · `Gemini API` · `FastAPI` · `Streamlit`

An AI-powered fraud investigation system designed around **graph-based transaction analysis**.

Traditional fraud detection systems can struggle when suspicious behavior is distributed across relationships between many transactions.

This project models those relationships as a graph and uses a **GraphSAGE Graph Neural Network** to identify structural patterns associated with fraudulent behavior.

### 🔬 What it does

- Models transaction relationships as graphs
- Uses GraphSAGE for graph-based fraud detection
- Identifies structural patterns including:
  - Money rings
  - Structuring
  - Smurfing
- Detects patterns that can be difficult for traditional rule-based approaches to identify
- Integrates Gemini to automatically generate regulatory-grade **Suspicious Activity Report (SAR)** narratives
- Provides an investigator-facing natural-language interface

### ⚡ Results

**~3 hours → < 60 seconds**

Reduced the manual investigation workflow from approximately **3 hours to under 60 seconds**, representing roughly a **180× speedup**.
